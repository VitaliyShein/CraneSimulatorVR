## How to use
Download the release you need:
- HMD-version for offline simulator launch on a pico 4 or meta quest 2 helmet, 3
- PC-VR for computer broadcast launch

## Как пользоваться
Скачайте релиз который вам нужен:
- HMD-version для автономного запуска симулятора на шлеме pico 4 или meta quest 2, 3 (установите на шлем с помощью программы SideQuest)
- PC-VR для запуска с трансляцией с компьютера

## Technologies:
- Unity 2022.3.62f3
- xr interaction toolkit 2.6.5
- PICO Unity OpenXR SDK 0.13.0
